# Habit Tracker API

Сервис для отслеживания привычек с интеграцией Telegram и системой напоминаний.

## 📋 Описание проекта

Проект представляет собой backend-часть для трекера привычек, вдохновленного книгой "Атомные привычки". Пользователи могут создавать полезные и приятные привычки, устанавливать напоминания и получать уведомления в Telegram.

### 🎯 Ключевые особенности

- Создание полезных и приятных привычек
- Система вознаграждений (приятные привычки или текстовые награды)
- Telegram-уведомления о времени выполнения привычек
- Публичные привычки для обмена опытом
- Пагинация (5 привычек на страницу)
- JWT-аутентификация
- Полное покрытие тестами (>80%)

## 🛠 Технологии

- **Python 3.12**
- **Django 6.0** + **Django REST Framework**
- **PostgreSQL** - основная база данных
- **Celery** + **Redis** - отложенные задачи и напоминания
- **Telegram Bot API** - уведомления
- **JWT** - аутентификация
- **Poetry** - управление зависимостями
- **Pytest** - тестирование (покрытие 84%)
